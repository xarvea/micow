# MICOW Launchpad

An educational, testnet-only meme-token launchpad on Robinhood Chain Testnet.

## Initial scope
- EVM wallet connection
- ERC-20 token creation
- On-chain bonding curve buy/sell
- Token profiles and trade history
- Future AMM graduation after verified integration

## Engineering requirements
- Testnet only during initial development
- Fixed token supply
- Slippage protection and invariant tests
- No private keys or credentials committed
- Independently written implementation
- No mainnet deployment before security review
